Démonstration d’une modale accessible construite avec un div (role="dialog", aria-modal, aria-labelledby, inert, hidden), sans l’élément natif <dialog>.

Démo

Principaux éléments pour réaliser ce composant accessible

  • button d’ouverture
  • div (fond assombri, parent de la modale)
    • hidden
  • div (modale)
    • role="dialog"
    • aria-modal="true"
    • aria-labelledby
    • tabindex="-1"
  • Titre de la modale (h2)
    • id référencé par aria-labelledby
  • button de fermeture
    • aria-label="Fermer la modale"
    • svg décoratif avec aria-hidden="true"
  • Contenu extérieur à la modale (.layout et #footer-container)
    • inert

Spécifications d’accessibilité

Attributs et propriétés

  • role="dialog" : placé sur le div de la modale, il indique aux technologies d’assistance qu’il s’agit d’une boîte de dialogue. Attribut statique.
  • aria-modal="true" : placé sur le même div, il indique que le contenu situé en dehors de la boîte de dialogue n’est pas disponible tant qu’elle est ouverte. Attribut statique, présent dans le HTML et jamais retiré par le JavaScript. Il ne remplace pas inert, qui rend réellement le reste de la page non interactif.
  • aria-labelledby="modal-title" : placé sur le div de la modale, il référence l’id du titre h2 visible. Ce titre fournit le nom accessible de la boîte de dialogue. Attribut statique.
  • tabindex="-1" : placé sur le div de la modale, il permet de lui donner le focus par programmation à l’ouverture, sans l’ajouter à l’ordre normal de tabulation. Attribut statique.
  • inert : posé par le JavaScript, à l’ouverture, sur .layout et #footer-container (tout le contenu de la page), et retiré à la fermeture. Les éléments inertes ne peuvent ni recevoir le focus, ni être activés à la souris, et ils sont retirés de l’arbre d’accessibilité. Il n’est jamais appliqué à un ancêtre de la modale ni à son fond : c’est pourquoi la modale est placée à la racine du body, à côté de ces deux éléments et non à l’intérieur.
  • hidden : présent dans le HTML sur le fond assombri (.modal-overlay), qui est le parent de la modale. Il est retiré à l’ouverture, avant de déplacer le focus, et réappliqué à la fermeture. Il retire la modale de l’affichage, de la navigation au clavier et de l’arbre d’accessibilité. Le CSS ne déclare display que sur .modal-overlay:not([hidden]), afin de ne pas neutraliser cet attribut.
  • aria-label="Fermer la modale" : le bouton de fermeture ne contient qu’une croix en SVG, il a donc besoin d’un nom accessible explicite. Attribut statique.
  • aria-hidden="true" sur le svg : la croix est purement décorative, son nom est déjà fourni par aria-label. Masquer le SVG évite qu’il soit exposé aux technologies d’assistance. Attribut statique.

En résumé, role, aria-modal, aria-labelledby, tabindex et aria-label sont statiques. Seuls hidden et inert sont gérés dynamiquement par le JavaScript.

Ouverture et fermeture

À l’ouverture, dans cet ordre :

  1. le bouton d’ouverture est mémorisé ;
  2. hidden est retiré du fond assombri : la modale devient visible et accessible ;
  3. inert est posé sur le reste de la page ;
  4. le défilement de l’arrière-plan est bloqué (overflow: hidden sur html) ;
  5. le focus est placé sur le div role="dialog".

À la fermeture, dans cet ordre :

  1. inert est retiré du reste de la page ;
  2. le défilement est rétabli ;
  3. hidden est réappliqué au fond assombri ;
  4. le focus est rendu au bouton d’ouverture.

inert doit être retiré avant de rendre le focus : un élément inerte ne peut pas le recevoir. Un clic sur le fond assombri ne ferme pas la modale : seuls le bouton de fermeture et la touche Escape la ferment.

Comportements clavier

  • Enter ou Space sur le bouton d’ouverture : ouvre la modale (comportement natif du button).
  • À l’ouverture : le focus se place sur le div role="dialog".
  • Tab depuis ce div : le focus va sur le premier élément interactif (le bouton de fermeture).
  • Shift + Tab depuis ce div : le focus va sur le dernier élément interactif (le bouton d’exemple).
  • Tab : le focus passe à l’élément interactif suivant dans la modale.
  • Tab depuis le dernier élément interactif : le focus revient au premier.
  • Shift + Tab depuis le premier élément interactif : le focus revient au dernier.
  • Escape : ferme la modale et rend le focus au bouton d’ouverture.
  • Enter ou Space sur le bouton de fermeture : ferme la modale et rend le focus au bouton d’ouverture.

      </svg>
    </button>

  </div>
</div>

JavaScript

/* Modale */
const openButton = document.getElementById('open-modal');
const overlay = document.getElementById('modal-overlay');
const dialog = overlay.querySelector('[role="dialog"]');
const closeButton = document.getElementById('close-modal');

// Éléments rendus inertes : jamais un ancêtre de la modale
const inertTargets = [
  document.querySelector('.layout'),
  document.getElementById('footer-container')
];

let trigger = null;

function getFocusableElements() {
  return Array.from(dialog.querySelectorAll('button, a[href], input, select, textarea'));
}

function openModal() {
  trigger = openButton;

  overlay.hidden = false;

  inertTargets.forEach(element => {
    element.inert = true;
  });

  document.documentElement.classList.add('modal-open');

  dialog.focus();
}

function closeModal() {
  inertTargets.forEach(element => {
    element.inert = false;
  });

  document.documentElement.classList.remove('modal-open');

  overlay.hidden = true;

  trigger.focus();
}

openButton.addEventListener('click', openModal);
closeButton.addEventListener('click', closeModal);

document.addEventListener('keydown', event => {
  if (overlay.hidden) return;

  if (event.key === 'Escape') {
    closeModal();
    return;
  }

  if (event.key !== 'Tab') return;

  const focusable = getFocusableElements();
  const first = focusable[0];
  const last = focusable[focusable.length - 1];
  const active = document.activeElement;

  if (!dialog.contains(active)) {
    event.preventDefault();
    (event.shiftKey ? last : first).focus();
  } else if (event.shiftKey && (active === first || active === dialog)) {
    event.preventDefault();
    last.focus();
  } else if (!event.shiftKey && active === last) {
    event.preventDefault();
    first.focus();
  }
});

Démonstration d’une modale accessible construite avec un div (role="dialog", aria-modal, aria-labelledby, hidden), sans l’élément natif <dialog>.

Démo

Principaux éléments pour réaliser ce composant accessible

  • button d’ouverture
  • div (fond assombri, parent de la modale)
    • hidden
  • div (modale)
    • role="dialog"
    • aria-modal="true"
    • aria-labelledby
    • tabindex="-1"
  • Titre de la modale (h2)
    • id référencé par aria-labelledby
  • button de fermeture
    • aria-label="Fermer la modale"
    • svg décoratif avec aria-hidden="true"
  • Contenu extérieur à la modale (.layout et #footer-container)
    • inert

Spécifications d’accessibilité

Attributs ARIA

  • role="dialog" : sur le div de la modale, il indique aux technologies d’assistance qu’il s’agit d’une boîte de dialogue. Attribut statique.
  • aria-modal="true" : sur le même div, il signale le caractère modal de la boîte de dialogue. Attribut statique, jamais retiré par le JavaScript. Il ne rend pas, à lui seul, le reste de la page non interactif : c’est inert qui s’en charge.
  • aria-labelledby="modal-title" : référence l’id du titre (h2) visible, qui fournit ainsi le nom accessible de la boîte de dialogue. Attribut statique.
  • tabindex="-1" : permet au div de la modale de recevoir le focus par programmation à l’ouverture, sans l’ajouter à l’ordre normal de tabulation. Attribut statique.
  • inert : posé par le JavaScript sur le reste de la page (jamais sur la modale ni sur son fond) tant qu’elle est ouverte, puis retiré à la fermeture. Un élément inerte ne peut ni recevoir le focus ni être activé, et il est retiré de l’arbre d’accessibilité.
  • hidden : présent dans le HTML sur le fond qui contient la modale. Il retire la modale de l’affichage, de la navigation au clavier et de l’arbre d’accessibilité lorsqu’elle est fermée. Géré dynamiquement par le JavaScript.
  • aria-label="Fermer la modale" : nom accessible du bouton de fermeture, dont le contenu visuel n’est qu’une croix. Attribut statique.
  • aria-hidden="true" sur le svg de la croix : purement décorative, elle est masquée aux technologies d’assistance puisque le nom du bouton est déjà fourni par aria-label. Attribut statique.

Comportements clavier

  • Enter ou Space sur le bouton d’ouverture : ouvre la modale et place le focus sur la boîte de dialogue.
  • Tab depuis la boîte de dialogue : le focus va sur le premier élément interactif (le bouton de fermeture).
  • Shift + Tab depuis la boîte de dialogue : le focus va sur le dernier élément interactif.
  • Tab : le focus passe à l’élément interactif suivant ; depuis le dernier, il revient au premier.
  • Shift + Tab : le focus passe à l’élément interactif précédent ; depuis le premier, il revient au dernier.
  • Escape : ferme la modale et rend le focus au bouton d’ouverture.
  • Enter ou Space sur le bouton de fermeture : ferme la modale et rend le focus au bouton d’ouverture.

HTML

  Ouvrir la modale
</button>

<!-- À placer à la racine du body, après #footer-container -->
<div class="modal-overlay" id="modal-overlay" hidden>
  <div
    class="modal"
    role="dialog"
    aria-modal="true"
    aria-labelledby="modal-title"
    tabindex="-1"
  >
    <button type="button" class="modal__close" id="close-modal" aria-label="Fermer la modale">
      <svg aria-hidden="true" viewBox="0 0 24 24" width="20" height="20">
        <path d="M5 5l14 14M19 5L5 19" fill="none" stroke="currentColor" stroke-width="2.5" stroke-linecap="round" />
      </svg>
    </button>

    <div class="modal__body">
      <h2 id="modal-title">Titre de la modale</h2>
      <p>Ceci est le contenu de la modale. Utilisez Tab pour parcourir ses éléments interactifs.</p>
      <div class="modal__actions">
        <button type="button" class="modal-button">Premier bouton d’exemple</button>
        <button type="button" class="modal-button">Second bouton d’exemple</button>
      </div>
    </div>
  </div>
</div>

JavaScript

/* Modale */
const openButton = document.getElementById('open-modal');
const overlay = document.getElementById('modal-overlay');
const dialog = overlay.querySelector('[role="dialog"]');
const closeButton = document.getElementById('close-modal');

// Éléments rendus inertes : jamais un ancêtre de la modale
const inertTargets = [
  document.querySelector('.layout'),
  document.getElementById('footer-container')
];

let trigger = null;

function getFocusableElements() {
  return Array.from(dialog.querySelectorAll('button, a[href], input, select, textarea'));
}

function openModal() {
  trigger = openButton;

  overlay.hidden = false;

  inertTargets.forEach(element => {
    element.inert = true;
  });

  document.documentElement.classList.add('modal-open');

  dialog.focus();
}

function closeModal() {
  inertTargets.forEach(element => {
    element.inert = false;
  });

  document.documentElement.classList.remove('modal-open');

  overlay.hidden = true;

  trigger.focus();
}

openButton.addEventListener('click', openModal);
closeButton.addEventListener('click', closeModal);

document.addEventListener('keydown', event => {
  if (overlay.hidden) return;

  if (event.key === 'Escape') {
    closeModal();
    return;
  }

  if (event.key !== 'Tab') return;

  const focusable = getFocusableElements();
  const first = focusable[0];
  const last = focusable[focusable.length - 1];
  const active = document.activeElement;

  if (!dialog.contains(active)) {
    event.preventDefault();
    (event.shiftKey ? last : first).focus();
  } else if (event.shiftKey && (active === first || active === dialog)) {
    event.preventDefault();
    last.focus();
  } else if (!event.shiftKey && active === last) {
    event.preventDefault();
    first.focus();
  }
});

/* Boîte de dialogue : 400 × 400 px, réduite si l'espace manque */
.modal {
  position: relative;
  width: 100%;
  max-width: 400px;

  max-height: 100%;
  background-color: #ffffff;
  border-radius: 6px;

}

.modal:focus {
  outline: 3px dashed var(--color-primary);

}
